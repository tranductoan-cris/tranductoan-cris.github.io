Privacy Policy – WhatIfTony Uploader

Last updated: November 8, 2026

WhatIfTony Uploader is a personal tool used only by the owner of the YouTube channel "What If, Tony?" to upload videos, thumbnails and captions, and to schedule them, on that channel.

Data accessed

With the owner's permission, the tool uses Google OAuth to access the owner's own YouTube channel through the YouTube Data API (scopes: youtube.upload and youtube.force-ssl). It does not access data of any other user.

How data is used and stored

The access token is stored only on the owner's own computer and is used only to upload and manage the owner's videos. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
